# Contributing to Cozy Stage

This repository is a mirror of Cozy Stage's internal development, synced at
each release. Issues are welcome — bug reports and reproduction steps are
especially useful. There is no SLA for responses.

Because development happens in a private monorepo, pull requests cannot be
merged directly. If you plan a larger change, please open an issue first so
we can fold it into the next sync.

For security concerns, please do not open a public issue — reach us via
https://sundaydesk.app/.
